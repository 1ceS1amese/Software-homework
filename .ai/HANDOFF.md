## 3. 关键决策（后续不得擅自更改，改动需回写文档）

| # | 决策 | 理由 |
|---|---|---|
| D-1 | 选课防超卖用**单条原子 UPDATE + 受影响行数判定**，而非悲观锁 | 逻辑短、无锁等待、易用集成测试证明 |
| D-2 | `enrollment` 用**状态字段 + 唯一键(student_id, teaching_class_id)**，退课置 `WITHDRAWN` 不删行 | 保留退选历史，重选不冲突 |
| D-3 | 权限用 **Spring Security 6 无状态 + JWT**，不引入 Session | 前后端分离，前端无服务端会话依赖 |
| D-4 | 持久层用 **MyBatis-Plus**，选课关键路径走显式 SQL | 需要手写原子语句与复杂联表统计 |
| D-5 | 前端按 **Vue 3 + Vite SPA + Nuxt UI** 设计，不引入 Nuxt SSR；按用户 2026-10-02 的要求完成重构，见 AS-03 | 当前路由统一 Nuxt UI；未接路由的旧版 Element Plus 源码仍保留 |
| D-6 | 成绩发布为**单向锁**，解锁需管理员操作并留审计 | 教学场景的刚性要求 |
| D-7 | 统一响应体 `{code,message,data,traceId}` + HTTP 语义双通道 | 便于前端统一拦截与排障 |
