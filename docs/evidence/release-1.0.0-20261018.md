## Git 与交付边界

功能分别提交并推送，已将功能分支正常快进合并到 `main`，保留既有分支与历史。正式标签为 `v1.0.0`，变更与升级步骤见 CHANGELOG 和 docs/18。最终说明提交后，应重新克隆远端镜像并逐一核验分支/标签、全部可达提交与对象字节、工作区受控文件内容和模式；最终回执通过交付记录提供，避免把说明文件自身的提交号递归写入文件。
